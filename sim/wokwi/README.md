Protocol harness for Wokwi ESP32-S3. Uses the reference mbedTLS AES-GCM function with a public zero test key and an in-memory packet link. Tests encryption, decryption, payload integrity, replay, tampering, length/version and session ordering. This is not original radio firmware and does not validate SX1262, GNSS, NVS persistence, antennas, supply or RF. Never use the test key in deployed equipment.
