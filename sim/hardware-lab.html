What these faults demonstrate

Power removed: node cannot execute. Radio initialization invalid: powered MCU cannot communicate over LoRa. Sensor disconnected: TX uses mock data rather than inventing a measured value. USB data removed: receiver can still receive but laptop logging stops. Virtual loss: transmitter runs while some messages never reach RX. Restoring connections recovers the modeled behavior. Resetting power clears receiver values but preserves session totals here.

Pin map is a reference for the repository's integrated-board design. Check the physical board revision, header labels and official schematic before using the optional input. Supply only 3.3 V-compatible signals to GPIO; never connect USB 5 V directly to a GPIO.
