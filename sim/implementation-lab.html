Minimum original telemetry hardware: two matching Heltec boards, two USB data cables and laptop. Actual position adds GNSS; redundancy adds a separately selected backup transport. Exact board revisions, backup device and range are needed before assigning their connections or claiming a complete physical setup. No jammer transmitter is part of this implementation.


Production work must define a shared packet format, unique AES-GCM nonces across restarts, private key provisioning, replay rejection, synchronized or session-based freshness, radio airtime scheduling and sequence deduplication. This teaching run uses a new random key and nonce for each new packet demonstration. Original files are preserved.
